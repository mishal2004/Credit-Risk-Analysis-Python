# Credit Risk Analysis Using Python

##  Project Overview
This project focuses on analyzing customer credit data to understand loan repayment behavior and identify potential credit default risks. Using Python, the dataset is cleaned, explored, and visualized to discover patterns related to customer income, employment, assets, debt, and loan status.

##  Objectives
- Analyze customer creditworthiness.
- Identify factors affecting loan defaults.
- Explore income, debt, assets, and loan amounts.
- Understand repayment patterns across employment categories.
- Discover relationships between financial variables.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Data Analysis
- Data cleaning and missing value treatment.
- Exploratory Data Analysis (EDA).
- Statistical analysis.
- Correlation analysis.
- Feature engineering.
- Data visualization.

##  Key Insights
- Approximately 71.8% of customers have good credit status.
- Approximately 28.2% have bad credit status.
- Customers with higher employment seniority generally show better creditworthiness.
- Higher loan amounts are associated with increased default risk.
- Previous credit records are an important indicator of credit risk.
- Part-time employees show the highest bad-credit rate.

##  Project Files
- `python project.ipynb` – Jupyter Notebook containing data cleaning, analysis, visualizations, and key insights.
- `credit_data.csv` – Dataset used for analysis.

##  Conclusion
This project demonstrates how Python can be used for credit risk analysis through data cleaning, exploratory data analysis, statistical techniques, and visualization. The findings help identify important factors associated with customer creditworthiness and loan defaults.
